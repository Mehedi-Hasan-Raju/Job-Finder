# Job Finder Web Application

A simple and responsive **Job Finder Web Application** built using the MERN stack.  
This project allows job seekers to search and apply for jobs, while employers can post and manage job listings.

---

## 🚀 Features
- User authentication (JWT-based login & registration)
- Job posting and management for employers
- Job search with filters (location, type, category)
- Apply for jobs directly
- User dashboard (Job seeker & Employer)
- Fully responsive design

---

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **Deployment:** Vercel (frontend), Heroku/Render (backend)

---

## 📂 Project Setup

### 1. Clone the repo

-git clone https://github.com/your-username/job-finder.git
-cd job-finder
-Install dependencies
---
npm install

Create a .env file in the server folder and add:

MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
---
Run the app

Start backend:

cd server
npm run dev
